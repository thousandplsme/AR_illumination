# 和歌山イルミ｜地域活性化を目指したARフォトカメラ

和歌山市の「けやき大通りイルミネーション」をより楽しんでもらうことを目的に制作した、スマートフォン向けARフォトカメラアプリです。現実の風景にデジタルの装飾を重ね、写真撮影を通じた新しい体験を提案しました。

> **制作実績**：校内制作コンペティション1位  
> **制作形態**：5人チーム（授業課題）  
> **開発環境**：Unity / C# / AR  
> **状態**：受賞時の作品をもとに改良中。本リポジトリには改良後のデータが含まれます。

## 担当と共同制作

リポジトリ管理者は、企画立案・仕様設計、UnityによるARおよび撮影機能の実装、チームの進行管理、成果発表を担当しました。

ほかのチームメンバーは、3Dモデリング、動画制作、ARマーカーのデザイン、UIデザインなどを担当しました。チーム制作物をすべてリポジトリ管理者個人の制作物として扱うものではありません。

## 受賞時の成果と制約

ARを活用した写真撮影体験を制作し、地域イベントの魅力向上をテーマに発表しました。

動画演出用の素材も制作しましたが、アプリへの統合時にエラーが発生し、受賞時のアプリには組み込めませんでした。動画は発表資料で紹介しました。

## このリポジトリに含まれる改良版の実装

ソースコード上では、以下の処理を確認できます。

- 画像マーカーの認識結果に応じたARオブジェクトの生成
- 4:3の撮影領域に合わせた表示調整
- スクリーンショットの撮影・プレビュー・撮り直し
- 端末の画像ギャラリーへの保存処理

これらは**改良版のコードから確認できる処理**であり、受賞当日にすべて実装済みだったことや、全端末で正常動作することを意味しません。

## 今後の確認事項

- 実機でのマーカー認識、撮影、保存の動作確認
- 画面サイズや操作性の確認
- 未統合の演出の扱いの検討

## 学んだこと

地域の課題を起点に体験を企画し、複数の専門分野を持つメンバーと協働しながら、仕様策定から実装・統合・発表まで進めました。限られた制作期間における優先順位付けと、制作素材の統合時に生じる技術的な問題への対応を経験しました。
